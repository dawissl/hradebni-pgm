Algoritmus je přesný postup složený z jednotlivých kroků, který vede k řešení daného problému.

Vlastnosti algoritmu: **hromadnost** (řeší celou třídu problémů), **determinovanost** (stejné vstupy = stejný výsledek), **konečnost** (algoritmus skončí), **rezultativnost** (vždy dospěje k výsledku).
