Objekty na haldě zaujímají paměť. Kdo ji uvolní? V C++ to dělá programátor ručně — a zapomene-li, nastane **memory leak** (únik paměti). V C# tuto práci přebírá **garbage collector** (GC).

---

## Jak GC funguje

Garbage collector automaticky prochází objekty na haldě a hledá ty, na které **neexistuje žádný odkaz** — jsou nedosažitelné. Takové objekty bezpečně uvolní.

```csharp
void Metoda()
{
    List<int> seznam = new List<int> { 1, 2, 3 };
    // seznam je na haldě, odkaz je na zásobníku
}
// Metoda skončila → odkaz ze zásobníku zmizel
// → GC může seznam uvolnit
```

GC neběží po každém přiřazení — spouští se v době, kdy systém potřebuje uvolnit paměť. Programátor to obvykle neovlivňuje a ani nemusí.

> 💡 Ruční volání `GC.Collect()` je v běžném kódu anti-pattern — GC ví lépe, kdy je vhodný čas.

---

## Dispose pattern a IDisposable

GC uvolní **paměť**, ale neumí uvolnit jiné zdroje — otevřené soubory, databázová připojení, síťové sokety. K tomu slouží vzor **Dispose**.

Třída, která drží systémový zdroj, implementuje rozhraní `IDisposable`:

```csharp
public interface IDisposable
{
    void Dispose();
}
```

Voláním `Dispose()` zdroj explicitně uvolníš — nemusíš čekat na GC.

---

## Blok `using` — automatické Dispose

Blok `using` zavolá `Dispose()` automaticky na konci bloku, i při výjimce:

```csharp
// Bez using — musíš volat Dispose ručně (a nezapomenout)
StreamReader sr = new StreamReader("soubor.txt");
string obsah = sr.ReadToEnd();
sr.Dispose();  // co když před tímto řádkem nastane výjimka?

// S using — Dispose se zavolá vždy
using (StreamReader sr = new StreamReader("soubor.txt"))
{
    string obsah = sr.ReadToEnd();
}  // tady se automaticky zavolá sr.Dispose()
```

`using` lze použít na jakoukoli třídu implementující `IDisposable` — `StreamReader`, `StreamWriter`, `SqlConnection`, `HttpClient` a další.

### Zkrácený zápis (C# 8+)

```csharp
using StreamReader sr = new StreamReader("soubor.txt");
string obsah = sr.ReadToEnd();
// Dispose se zavolá na konci aktuálního scope (metody, bloku)
```

---

## Kdy používat `using`

Kdykoli pracuješ s třídou implementující `IDisposable` — a to bez výjimky. Poznáš ji tak, že má metodu `Dispose()` nebo Visual Studio ji zvýrazní.

Nejčastější třídy vyžadující `using`:

| Třída | Zdroj |
|---|---|
| `StreamReader`, `StreamWriter` | Soubory |
| `SqlConnection`, `SqlCommand` | Databázová připojení |
| `HttpClient` | Síťová připojení |
| `Graphics` | GDI+ grafický kontext |
| `Bitmap`, `Image` | Obrázky v paměti |

## Shrnutí

| Pojem | Vysvětlení |
|---|---|
| Garbage collector | Automaticky uvolňuje nedosažitelné objekty z haldy |
| Memory leak | Objekt v paměti, na který neexistuje odkaz, ale GC ho ještě neuvolnil — v C# vzácné |
| `IDisposable` | Rozhraní pro třídy držící systémové zdroje |
| `Dispose()` | Explicitní uvolnění zdroje |
| `using` blok | Automaticky zavolá `Dispose()` i při výjimce |
